Changelog
=========

Version 1.0.0 (2024-11-13)
--------------------------

Initial release with complete modular architecture.

Features
^^^^^^^^

- **LogAnalyzer**: Auto-detection of log characteristics
- **ProcessMiner**: Inductive Miner with quality metrics
- **LogSimulator**: SimPy-based discrete-event simulation
- **LogValidator**: Statistical log comparison
- **ORECalculator**: Operating Room Effectiveness metrics
- **ProcessMiningPipeline**: Unified facade API
- **Enriched XES**: Support for operational attributes

Documentation
^^^^^^^^^^^^^

- Complete Sphinx documentation
- API reference for all modules
- Quickstart guide with examples
- Enriched XES format specification

Infrastructure
^^^^^^^^^^^^^^

- Modular architecture - all components independent
- Type hints throughout codebase
- Comprehensive docstrings (Google style)
- Streamlit web application
